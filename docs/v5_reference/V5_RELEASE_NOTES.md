# TijaPass V5 — Financial Intelligence update

**Built from:** TijaPass V4 Full Ecosystem. Core role flows remain in place.

**New:** Smart Accounting menu; simple bilingual entries; optional browser speech; receipt camera preview + optional device-supported TextDetector; statement import for CSV/TSV/basic XLSX; staging/evidence queue; explainable classification with reviewed-correction learning; duplicate and running-balance checks; TFL controlled review; double-entry journals; loan split / stock-vs-COGS / transfer rules; opening snapshot configuration; P&L, cashflow, financial position, trial balance; ledger export; manual closing balance comparison; separate data-backed finance-readiness gate; accounting schema extension and developer/BOT scripts.

**Critical fix:** manually selecting a Linked bank/mobile source in the older V4 transactions page no longer automatically makes the new entry verified. Only completed entries explicitly verified are included in that legacy evidence path.

**Still pending:** authenticated accounts, permanent server data, regulated wallet rails, provider APIs, external OCR, real AI model, FI permission enforcement on backend, verified source reconciliations, full accrual accounting and independent assurance.
