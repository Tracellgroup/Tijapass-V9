# V7 developer / BOT demonstration — 7–10 minutes

**Opening statement:** TijaPass is an MSME financial-record and credit-readiness concept. This browser pilot demonstrates controlled workflows, not regulated live payments or approved banking APIs.

1. **Language (1 min):** Switch English → Kiswahili from header. Show the customer overview and move to Smart Accounting. Names and account reference codes are not translated.
2. **Low-literacy capture (2 min):** Customer → Guided entry, cash receipt, `Juma`, `20,000`, `Nimeuza mchele kwa Juma`. Tap microphone if browser supports speech; customer checks the transcript; validate and confirm. Explain the output is provisional until corroborated/reconciled.
3. **Prevention (1 min):** Change counterparty to Asha while leaving purpose `kwa Juma`; show reasoned correction request. Change direction or category to deliberately contradictory values to show a hold.
4. **Multiple sources (1 min):** Import fictional statement CSV. Explain rows need counterparty/business-purpose verification and suspected matching receipts are linked as evidence rather than counted twice.
5. **Super Accountant (1 min):** TFL Admin → Smart Accounting → Review. Show a `20,000,000` anomalous receipt; concise flags, request additional evidence, and send correction back to customer.
6. **Integrity (1 min):** Show double-entry financial statements, review audit events and reverse a posted example with a reason. A contra entry reverses impact while preserving history.
7. **Developer/BOT ask (1–2 min):** Discuss real AI model integration, regulated partner API conditions, security, accounting assurance, source-quality tiers, permissions and sandbox pathway.

**Important:** No independent bank transaction authentication or production AI runs behind this static pilot. No genuine customer ID or financial statement should be uploaded to public demo hosting.
