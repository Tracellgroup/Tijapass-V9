# V6 release notes — 12 October 2026

Upgraded V5 role-based TijaPass prototype: original logos corrected/cropped with transparent backgrounds, redesigned accounting cards and mobile layouts, bilingual English/Kiswahili accounting user flow, account-source neutral statement uploads, required payer and business purpose, customer confirmation of every imported record, TFL risk-based anomaly approvals, exact duplicate prevention and evidence linking without second ledger posting. Expanded unit tests, developer handoff and backend schema extension.

**Limitations retained**: browser demo, no multi-device persistence, no live money/provider connection, rules-based instead of integrated LLM, incomplete translations of inherited screens, no full build performed because npm access was unavailable in authoring environment. Netlify build/testing required before use.
